# 1.0.3 iOS test build

This is a local test build based on the corrected 1.0.2 source (`0c73102`).
The stable 1.0.2 GitHub release remains available while testing proceeds.

## Changes to test

- Sixteen pads in a 4×4 grid, with ten banks A–J. Existing pad numbers and stored cues are preserved.
- Mark fills empty slots in the current bank, then continues through subsequent banks without overwriting saved cues. The visible bank changes when a cue is marked in the next bank. Mark stops at a full bank J.
- An iOS cue jump schedules a 3 ms incoming ramp and, during playback, a short outgoing tail through the same speed/pitch chain. No fade timer delays the trigger. Audio-session activation is skipped when the engine is already running. Audible results and physical touch-to-sound latency require device testing.
- Empty native snapshots no longer make an unloaded song appear loaded or erase the saved playhead. The shared player saves once a second and on transport changes; iOS also saves its native track/playhead for background playback recovery. Reopening stays paused until Play.

## SP-404MKII

Select **SP-404MKII · MIDI Mode A** in the cue page's MIDI preset selector and set the controller to Mode A.

| Physical pads | MIDI notes |
| --- | --- |
| 1, 2, 3, 4 | 48, 49, 50, 51 |
| 5, 6, 7, 8 | 44, 45, 46, 47 |
| 9, 10, 11, 12 | 40, 41, 42, 43 |
| 13, 14, 15, 16 | 36, 37, 38, 39 |

Channels 1–10 select banks A–J. Native channel indices are zero-based internally. Channels 11–16 are ignored by this preset. An empty pad marks the current native playhead; an assigned pad triggers it. Enable Overwrite to replace assigned cues. Note Off and velocity-zero Note On release pad highlighting without stopping one-shot playback. Velocity is retained by the mapping and visual state; it does not change the continuous track's playback volume.

**Legacy · 12 pads (notes 36–47)** retains ascending pad mapping and uses the selected bank on any MIDI channel. CC 20 onward also maps pads in each preset; zero-valued CC messages release rather than retrigger.

Selecting Legacy changes the mobile and desktop main pad grids to twelve pads and makes Mark roll over after pad 12. Mode A/B show sixteen pads and roll after pad 16. The preset is persisted locally and restored when reopening. Cues on hidden pads 13–16 are not deleted and reappear when returning to a sixteen-pad preset.

On Android/iOS, Legacy is arranged in three columns and four rows: 1–3, 4–6, 7–9, 10–12. Mode A/B remain 4×4. Desktop keeps its four-column layout.

The mapping resolver accepts custom pad-note arrays and bank/channel tables; no new MIDI dependency is required. Mode B is included; a custom mapping editor is not part of this release.

Source: [Roland SP-404MKII v5.50 MIDI note map](https://static.roland.com/manuals/sp-404mk2_reference_v550/en-US/8012353178593931.html).

## Automated checks

```sh
pnpm typecheck
node scripts/check-controller-mapping.mjs
MUSIKE_TEST_PLATFORM=ios node scripts/check-android-cues.mjs
node scripts/check-android-cues.mjs
```

The mapping checks cover all 160 Mode A pad/bank combinations, Note Off, velocity-zero Note On, velocity, bank isolation, legacy mappings and a custom mapping. Bridge checks cover 16-pad Mark rollover, MIDI marking/triggering, and first Play after reload at the stored position, alongside existing cue/loop/rate/playlist checks.

## Device checks

1. Rapidly retrigger cues on bass-heavy and sustained material, paused and playing, in both speed modes. Compare clicks and response feel with 1.0.2.
2. Fill A1–A16, press Mark again, and verify B1 is marked and bank B becomes visible. Verify existing cue marks are preserved.
3. Pause midway through a song, force-close, reopen, and press Play. Repeat after background playback; verify song and position.
4. Connect the SP-404MKII, test all 16 physical pads, bank channels A–J, empty-pad marking, Overwrite, releases and repeated hits. Verify changing channels never triggers a different bank.

## Mode B and release scope

Mode B is available alongside Mode A and Legacy 12-pad. With the SP-404MKII's default channel settings, channel 1 addresses A–E and channel 2 addresses F–J. The five note ranges are 12–27, 28–43, 44–59, 60–75 and 76–91, with the same reversed row ordering as Mode A. Select the matching mode on the sampler. The app follows the bank on the first pad message; a bank-selection button alone may not send MIDI.

The Standard preset was removed from both desktop and mobile selectors. A previously saved Standard selection falls back to Mode A.

The shared desktop implementation now includes sixteen pads, sequential Mark across banks, MIDI preset selection and MIDI overwrite. Desktop keeps its existing Web Audio cue micro-fade; Android keeps its cached ExoPlayer seeking. The new sample-level transition is iOS-specific. Further engine/latency changes are deferred to the next release.
